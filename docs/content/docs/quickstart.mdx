## Check the host

Use Linux with Python 3.12 or later. Run these checks as the account that will launch the benchmark.

```bash
python --version
docker info
```

The SDK runs Containerlab deployment and teardown through `sudo -n`. Ask your administrator to authorize the trusted Containerlab executable and required host cleanup commands for unattended use. For Docker permissions or offline installation, see [Host setup](/docs/debug-operate/host-setup).

## Install NetOpsBench

```bash
git clone https://github.com/NetX-lab/NetOpsBench.git
cd NetOpsBench
python -m venv .venv
source .venv/bin/activate
pip install -e ".[agent]"
python -m netopsbench.platform.runtime.build_tools
docker build -f containers/client/Dockerfile -t netopsbench-client:pingmesh-v2 .
```

The installer verifies and installs the project's private Containerlab v0.77.0 executable. Run the remaining commands from the repository root in the same shell.

## Run the XS case

Set `OPENAI_API_KEY` in your environment for the reference agent. Prepare the XS scenarios, then start the lab and run one diagnosis.

```bash
netopsbench benchmark prepare --scales xs
PYTHONPATH=. python examples/01_run_scenario.py --vendor openai \
  --scenario scenarios/generated/xs/generated_link_down_xs_001.yaml
```

## Find the report

The example prints a summary and tears down its lab. The saved report is under `.netopsbench/runs/<run-id>/report.json`. List completed runs or inspect their agent traces with:

```bash
netopsbench result list
netopsbench trace view
```

To run several cases on the same lab, continue to [Running Benchmarks](/docs/run-benchmarks/run-scenario-vs-suite).
